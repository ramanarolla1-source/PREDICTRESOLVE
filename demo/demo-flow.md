# PredictResolve — Demo Flow

## 1. Purpose

This guide explains the end-to-end PredictResolve demonstration.

The demo shows how a prediction can remain private while its outcome is externally verified, confidentially resolved, and settled as an enforceable on-chain FXRP transaction.

The core product flow is:

**Predict → Verify → Resolve → Settle**

The demonstration uses a synthetic sports-event scenario.
