# PredictResolve — Demo Guide

## 1. Purpose

This guide explains the end-to-end PredictResolve demonstration.

The demo shows how a prediction can remain confidential while its real-world outcome is independently verified, privately resolved inside a Flare Trusted Execution Environment, preserved through a Trust Receipt, and finally enforced through an on-chain FXRP settlement.

The product flow is:

> **Predict. Verify. Resolve. Settle.**

The demonstration uses a synthetic sports-event scenario.
